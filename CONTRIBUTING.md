# Contributing to ArchKnowledge

Each repository describes its own contribution rules in its README or its own `CONTRIBUTING.md`. For knowledge content, the rules of [Architecture-Knowledge-Graph](https://github.com/ArchKnowledge/Architecture-Knowledge-Graph/blob/main/CONTRIBUTING.md) apply in every repository:

- Every change is a pull request; nobody pushes to `main`.
- Never invent sources; use `sources: []` when nothing is verified.
- Approval is a human decision, recorded in a governance record, never a field edit.
- Disclose AI assistance in the pull request. Objects created or changed with AI assistance are at most `proposed`.

Feedback on published content: use the feedback link on any page of https://archknowledge.github.io.
