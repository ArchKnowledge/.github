# ArchKnowledge

A governed, interconnected knowledge graph for data and enterprise architecture: concepts, patterns, decisions, standards, governance, reference architectures and assessments.

- **Website:** https://archknowledge.github.io (Community edition)
- **Feedback:** use the feedback link on any page of the website.

Every knowledge object has one ID, typed relationships and a lifecycle. Decision trees, scoring models and rules are machine-readable, and every change is validated and reviewed before it is published.
