# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful, welcoming and constructive; critique ideas, not people; assume good faith; and accept that architectural disagreements are resolved through the documented governance process — by evidence, decision rights and recorded decisions — not by persistence or seniority.

## Reporting

Report unacceptable behaviour privately to the owners of the ArchKnowledge organisation via GitHub. Reports are handled confidentially. The repository owner decides on and enforces consequences in line with the Contributor Covenant enforcement guidelines.
